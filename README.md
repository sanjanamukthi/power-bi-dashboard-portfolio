# Power BI Dashboard Portfolio

A collection of interactive Power BI dashboards developed during college training, focused on data visualization, business analytics, KPI reporting, variance analysis, forecasting, and Pareto analysis.

## 📊 Dashboard Projects

### 1. HR Analytics Dashboard

An interactive HR analytics dashboard covering workforce and attrition-related analysis.

**Key Analysis:**
- Total headcount and active employees
- Attrition and attrition rate
- Department-wise analysis
- Job role analysis
- Education field analysis
- Age and gender analysis
- KPI cards and interactive slicers
- Trend analysis

**[View HR Analytics Dashboard →](./HR-Analytics)**

---

### 2. Sales, Budget & Forecast Dashboard

An interactive dashboard for comparing actual performance with budget and forecast values.

**Key Analysis:**
- Actual vs Budget
- Actual vs Forecast
- Budget vs Forecast
- Variance analysis
- Sales performance trends
- Regional analysis
- Country-wise analysis
- Cost element analysis
- IT area analysis

**[View Sales, Budget & Forecast Dashboard →](./Sales-Budget-Forecast)**

---

### 3. Retail & Pareto Analytics Dashboard

An interactive retail analytics dashboard focused on sales contribution, Pareto analysis, and target performance.

**Key Analysis:**
- Sales revenue analysis
- Pareto analysis and cumulative percentage
- Adjustable cumulative percentage threshold
- Brand-wise analysis
- Product Group analysis
- State-wise analysis
- Plant-wise analysis
- Sales revenue trends
- Deviation from target

**[View Retail & Pareto Analytics Dashboard →](./Retail-Pareto-Analytics)**
