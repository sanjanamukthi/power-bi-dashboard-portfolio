
# Sales, Budget & Forecast Dashboard

## Overview

Interactive Power BI dashboard developed during college training to analyze sales performance and compare actual results with budget and forecast values.

## Analysis Covered

- Actual vs Budget analysis
- Actual vs Forecast analysis
- Variance analysis
- Sales performance tracking
- Trend analysis
- Interactive filtering and KPI visualization

## Tools Used

- Microsoft Power BI
- Data visualization
- Business analytics
- Variance analysis
